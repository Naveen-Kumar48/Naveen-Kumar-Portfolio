# Naveen Kumar - Full Stack Developer Portfolio

Welcome to the source code for my personal portfolio! This project is an Angular application built to showcase my skills, projects, and professional experience as a Full Stack Developer specializing in the MERN stack and Next.js.

## Tech Stack
- **Framework:** Angular (v17+)
- **Styling:** Tailwind CSS with custom thematic glass-morphism UI
- **Animations:** GSAP (GreenSock) for scroll and timeline animations
- **Icons:** Google Material Icons

## Getting Started

To run this project locally, follow these steps:

### Prerequisites
- Node.js (v18 or higher recommended)
- Angular CLI (`npm install -g @angular/cli`)

### Installation & Execution
1. Clone the repository:
   ```bash
   git clone https://github.com/Naveen-Kumar48/portfolio.git
   cd portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm start 
   ```
   *(Or `npm run dev` if you need to run it alongside specific environment variables)*

## Features
- **3D Interactive Hero Section:** Powered by a minimal 3D engine (or custom CSS/SVG).
- **Responsive Layout:** fully optimized for mobile, tablet, and desktop environments.
- **Dynamic Projects Showcase:** Easily updatable data structure mapping to UI components.
- **Dark/Light Theme Toggle:** Handled seamlessly with local storage persistence.
